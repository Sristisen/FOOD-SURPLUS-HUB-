# Second Helping — Food Surplus Hub redesign

Open `index.html` in a browser. It is a self-contained front-end prototype that uses Tailwind CDN, Font Awesome, and remote food photography, so an internet connection helps the external assets load.

The redesign keeps the original JavaScript state engine and interactions intact while changing the visual language, branding, colors, spacing, and selected UI copy. The map, QR scan, partner verification, and live metrics are simulations rather than connected production services.
